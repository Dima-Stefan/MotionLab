# MotionLab

Detectarea intervalelor de mișcare în video – varianta 21A (diferență între cadre consecutive).
Echipa: Pîrvu Mihai-Alexandru, Dima Sever-Ștefan · Grupa 421 C

## Instalare
```
python -m venv .venv
.venv\Scripts\activate      # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
```

## Rulare
```
python main.py
```

## Teste
```
pytest
```
